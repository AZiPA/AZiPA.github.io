تمام دستورات مدیریتی منحصراً در چت خصوصی (`ctx.chat.type === "private"`) اجرا می‌شوند و بر اساس رتبه ۵ سطحی توسط `commandGuardMiddleware` کنترل می‌گردند.

## دستورات اصلی (دسته‌بندی‌شده بر اساس نقش)

### دستورات عمومی (رتبه ۰ — کاربر عادی)

| دستور | شرح عملکرد |
| :--- | :--- |
| `` `/start [code\|code_pin]` `` | خوش‌آمدگویی، تحویل بسته با `code` یا بازگشایی مستقیم بسته پین‌دار با `code_pin`. |
| `/help` | نمایش راهنمای دستورات و نحوه استفاده متناسب با سطح دسترسی کاربر. |

### دستورات ادمین (رتبه ۲ — ادمین و بالاتر)

| دستور | شرح عملکرد |
| :--- | :--- |
| `/upload` | شروع نشست آپلود تک‌فایل. |
| `/batch` | شروع نشست آپلود دسته‌ای (تا `20` آیتم در هر نشست، سقف قطعی `25` آیتم در هر بسته). |
| `/done` | نهایی‌سازی نشست آپلود یا ویرایش فعال و دریافت لینک عمیق بسته. |
| `/cancel` | لغو نشست آپلود، ویرایش یا پرامپت تعاملی فعال. |
| `/edit <code>` | باز کردن بسته موجود برای افزودن فایل یا تغییر تنظیمات با Compare-And-Swap اتمیک. |
| `/review <code>` | بازبینی فراداده و آیتم‌های بسته (شامل ابزار کمکی درون‌خطی `/del_<index>` حین بازبینی/ویرایش). |
| `` `/setname <code> <title\|clear>` `` | تنظیم یا پاک کردن عنوان نمایشی روی یک بسته موجود. |
| `/search <query>` | جست‌وجوی بسته‌ها همراه با نرمال‌سازی حروف عربی/فارسی. |
| `/stats` | نمایش آمار دانلودها، کاربران و بسته‌ها (کش‌شده در حافظه به مدت `5` دقیقه). |
| `/top` | نمایش رتبه‌بندی بسته‌های دارای بیشترین دانلود. |
| `/channels` | باز کردن بخش مدیریت کانال‌های عضویت اجباری. |
| `` `/addchannel <id\|forward> [limit] [btn]` `` | افزودن کانال عضویت اجباری با شناسه یا فوروارد پست به همراه سقف عضو و متن دکمه اختیاری. |
| `/delchannel <channel_id>` | حذف یک کانال از فهرست عضویت اجباری. |
| `/setchannelbtn <id> <label>` | تغییر متن دکمه اینلاین عضویت برای یک کانال عضویت اجباری. |
| `/setverifybtn <label>` | سفارشی‌سازی متن دکمه تایید عضویت اجباری. |
| `/setexpiry <code> <duration>` | تنظیم یا به‌روزرسانی مدت انقضای یک بسته. |
| `` `/setpass <code> <pin\|off\|clear>` `` | تنظیم پین ۴ تا ۳۲ کاراکتری SHA-256 روی بسته یا حذف رمز عبور. |
| `/postbundle <code> [channel_id]` | انتشار یا به‌روزرسانی پست دانلود بسته در `[channel_id]` یا `pub_channel_id`. |
| `/rotatelink <code>` | چرخش لینک دسترسی بسته به یک UUID جدید و همگام‌سازی دکمه پست کانال منتشرشده. |

### دستورات سوپرادمین (رتبه ۳ — سوپرادمین و مالک)

| دستور | شرح عملکرد |
| :--- | :--- |
| `/botprofile` | باز کردن تنظیمات پروفایل ربات. |
| `/settings` | نمایش و به‌روزرسانی تنظیمات سراسری پیکربندی ربات. |
| `/setdailylimit <count>` | تنظیم سهمیه دانلود روزانه کاربران عادی (`daily_limit`). |
| `` `/setpubchannel <-100...\|off\|clear>` `` | تنظیم، غیرفعال‌سازی یا پاک کردن کانال عمومی پیش‌فرض برای `/postbundle`. |
| `/admins` | نمایش فهرست ادمین‌ها و سوپرادمین‌های ثبت‌شده. |
| `/addadmin <user_id> [role]` | ارتقای `<user_id>` به `admin` یا `super_admin` (سقف ادمین عادی `MAX_ADMINS = 10`). |
| `/deladmin <user_id>` | سلب امتیاز ادمین یا سوپرادمین از `<user_id>`. |
| `/ban <user_id> [days]` | مسدود کردن کاربر به مدت `1–3650` روز (یا دائمی در صورت حذف تعداد روز). |
| `/unban <user_id>` | رفع مسدودیت فعال کاربر. |
| `/addvip <user_id> [days]` | اعطای وضعیت VIP برای `[days]` روز یا مادام‌العمر (`expires_at = 0`). |
| `/vips` | نمایش فهرست کاربران VIP فعال و تاریخ انقضا. |
| `` `/delvip <user_id\|all>` `` | حذف وضعیت VIP از `<user_id>` یا پاک‌سازی همه رکوردهای VIP. |
| `/clearvips` | پاک‌سازی کامل تمام رکوردهای جدول `vips`. |

### دستورات مالک (رتبه ۴ — انحصاری مالک)

| دستور | شرح عملکرد |
| :--- | :--- |
| `/maintenance` | روشن یا خاموش کردن حالت تعمیرات بدون نوشتن در D1 برای غیرادمین‌ها. |
| `/setfilelimit <count>` | تنظیم سقف دانلود به ازای هر لینک (`file_daily_limit`). |
| `/setautodel <seconds>` | تنظیم تاخیر حذف خودکار (`0` برای خاموش یا `10` تا `172800` ثانیه). |
| `/setbundlettl <duration>` | تنظیم زمان انقضای پیش‌فرض برای بسته‌های تازه ساخته‌شده. |
| `` `/setlogchannel <id\|owner\|off>` `` | هدایت هشدارهای عملیاتی و پشتیبان‌ها به کانال (`-100...`)، پیوی مالک (`owner`) یا خاموش کردن (`off`). |
| `/factoryreset confirm` | ارسال فایل پشتیبان JSON از `system_config` و `force_channels` و سپس پاک‌سازی داده‌های زمان اجرا در D1. |
| `/restore` | با ریپلای روی فایل پشتیبان `.json` (تا `256 KB`) جدول‌های `system_config` و `force_channels` را به صورت اتمیک بازیابی می‌کند. |

## بایندینگ‌ها و Secretهای `Env` در کلادفلر ورکر

| بایندینگ / Secret | نوع | کاربرد |
| :--- | :--- | :--- |
| `DB` | D1 Database | اتصال به دیتابیس کلادفلر D1 (`filestore-db`). |
| `FILESTORE_ANALYTICS` | Analytics Engine | اتصال به دیتاست `filestore_analytics` برای تله‌متری لبه و هشدارها. |
| `BOT_TOKEN` | Secret *(اجباری)* | توکن HTTP ربات در Telegram Bot API. |
| `OWNER_ID` | Secret *(اجباری)* | شناسه عددی تلگرام (`۱ تا ۱۵` رقم) جهت شناسایی مالک رتبه ۴. |
| `WEBHOOK_PATH` | Secret *(اجباری)* | پسوند محرمانه مسیر HTTP برای `POST /<WEBHOOK_PATH>`. |
| `WEBHOOK_SECRET` | Secret *(اجباری)* | توکن محرمانه (`>= 16` کاراکتر) تطبیق‌یافته با `X-Telegram-Bot-Api-Secret-Token`. |
| `BOT_USERNAME` | Secret / Var *(پیشنهادی)* | از فراخوانی `getMe` هنگام شروع سرد برای ساخت لینک عمیق جلوگیری می‌کند. |
| `BOT_FIRST_NAME` | Var *(اختیاری)* | نام نمایشی جایگزین ربات (`"File Store Bot"`). |
| `STORAGE_CHANNEL_ID` | Secret / Var *(اختیاری)* | شناسه کانال ذخیره خصوصی (`-100...`) برای آینه‌سازی و `copyMessages()` در ۱ ساب‌ریکوئست. |
| `LOG_CHANNEL_ID` | Secret / Var *(اختیاری)* | شناسه کانال لاگ خصوصی (`-100...`) برای هشدارها و خروجی پشتیبان. |
| `ENABLE_QUOTA_CACHE` | Var *(اختیاری)* | مقدار `"false"` کش سهمیه ۵ دقیقه‌ای درون حافظه را غیرفعال می‌کند. |

## کلیدهای پویای `system_config`

| کلید | کاربرد |
| :--- | :--- |
| `maintenance_mode` | فعال‌سازی قفل تعمیرات بدون نوشتن در D1 برای غیرادمین‌ها. |
| `daily_limit` | سقف دانلود روزانه استاندارد رتبه ۰ (پیش‌فرض `10`؛ VIPها `5×` دریافت می‌کنند). |
| `file_daily_limit` | سقف دانلود هر لینک برای رتبه ۰ (پیش‌فرض `3`؛ VIPها `3×` دریافت می‌کنند). |
| `auto_delete_seconds` | تایمر پیش‌فرض حذف خودکار (`0` یا `10`–`172800` ثانیه) صف‌شده در `deletion_queue`. |
| `bundle_ttl_seconds` | بازه انقضای پیش‌فرض اعمال‌شده روی بسته‌های جدید. |
| `global_protect_content` | اعمال سراسری `protect_content` روی بسته‌های تازه ساخته‌شده. |
| `log_channel_id` | مقدار جایگزین زمان اجرا برای ارسال هشدارها و خروجی JSON دستور `/factoryreset`. |
| `pub_channel_id` | کانال عمومی پیش‌فرض هدف برای دستور `/postbundle`. |
| `fj_verify_btn_text` | متن سفارشی دکمه اینلاین تایید عضویت اجباری. |
| `bot_lang` | زبان پیش‌فرض رابط کاربری ربات (`en` یا `fa`). |

## ثابت‌های سخت‌کدشده زمان اجرا (`src/config.ts`)

تعریف‌شده در گروه‌های `LIMITS`، `UI_CONFIG`، `QUOTA_CACHE_CONFIG` و `LOGGING_CONFIG` در فایل `src/config.ts`:

| گروه / ثابت | مقدار | نقش |
| :--- | :--- | :--- |
| `LIMITS.MAX_PER_SESSION_UPLOAD` | `20` | حداکثر تعداد فایل قابل آپلود در یک نشست `/batch`. |
| `LIMITS.MAX_BUNDLE_ITEMS` | `25` | سقف قطعی تعداد آیتم در هر بسته. |
| `LIMITS.CHUNK_DELIVERY_SIZE` | `10` | تعداد آیتم تحویل‌شده در هر برش (`dl:p:<code>:<offset>`). |
| `LIMITS.SESSION_TIMEOUT_SEC` | `600` | تایم‌اوت عدم فعالیت (`۱۰ دقیقه`) برای نشست‌های باز آپلود/ویرایش. |
| `LIMITS.MAX_FORCE_JOIN_CHANNELS` | `8` | حداکثر تعداد کانال‌های عضویت اجباری قابل تنظیم. |
| `LIMITS.MEMBERSHIP_CONCURRENCY` | `6` | حداکثر تعداد سوکت خروجی هم‌زمان برای بررسی عضویت اجباری. |
| `LIMITS.FORCE_JOIN_THROTTLE_SEC` | `3` | کولداون میان کلیک‌های بررسی عضویت اجباری. |
| `LIMITS.MAX_ADMINS` | `10` | حداکثر ادمین‌های عادی قابل مدیریت توسط سوپرادمین‌ها. |
| `LIMITS.PASSCODE_MAX_ATTEMPTS` | `5` / `1800`s | آستانه قفل ضد بروت‌فورس (`5` خطا → `30` دقیقه مسدودیت). |
| `UI_CONFIG.coloredButtons` | `true` | فعال‌سازی رنگ دکمه‌های Bot API 9.4 (`primary`، `success`، `danger`). |
| `UI_CONFIG.customEmojiIconsEnabled` | `false` | به طور پیش‌فرض غیرفعال جهت پیشگیری از خطای HTTP 400 تلگرام روی ایموجی‌های ناموجود. |
| `QUOTA_CACHE_CONFIG` | `300`s (`5` دقیقه) | پنجره کش `CappedMap` درون حافظه برای سهمیه و آمار (قابل کنترل با `ENABLE_QUOTA_CACHE`). |
| `LOGGING_CONFIG` | کولداون `3600`s | جلوگیری از تکرار هشدارهای `isD1FreeTierError()` با کولداون ۱ ساعته. |
