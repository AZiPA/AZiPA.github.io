تمام تعامل‌های ربات در چت خصوصی انجام می‌شوند. دستورات بر اساس سلسله‌مراتب ۵ سطحی نقش‌ها کنترل می‌شوند و رفتار زمان اجرا ترکیبی از رکوردهای پایدار `system_config` در SQLite و ثابت‌های تعریف‌شده در `tgcloud/lib/` است.

## مرجع دستورات بر اساس سطح دسترسی

### دستورات عمومی (سطح ۰ — کاربر عادی)

| دستور | شرح عملکرد |
| :--- | :--- |
| `/start [code]` | نمایش منوی خوش‌آمدگویی یا باز کردن لینک عمیق بسته (`<code>`) برای تحویل فایل. |
| `/help` | نمایش راهنمای دستورات متناسب با سطح دسترسی کاربر. |
| `/cancel` | لغو نشست آپلود فعال، بسته چندفایلی یا حالت تعاملی فعلی. |

### دستورات ادمین (سطح ۲ — ادمین و بالاتر)

#### آپلود، بسته‌ها و انتشار

| دستور | شرح عملکرد |
| :--- | :--- |
| `/upload` | شروع فرآیند آپلود تک‌فایل. |
| `/batch` | شروع نشست آپلود دسته‌ای (تا سقف `25` آیتم). |
| `/done` | نهایی‌سازی نشست آپلود فعال و تولید لینک بسته. |
| `/manage <code>` *(معادل `/edit`)* | باز کردن هاب تعاملی بسته برای ویرایش آیتم‌ها، محافظت محتوا، انقضا و پرچم‌ها. |
| `/review <code>` | پیش‌نمایش محتوا و مشخصات بسته بدون کسر سهمیه دانلود. |
| `/del_<idx>` | حذف آیتم شماره `<idx>` در حین نشست آپلود یا ویرایش. |
| `` `/setname <code> <title\|clear\|off>` `` | تنظیم، پاک کردن یا غیرفعال‌سازی عنوان نمایشی سفارشی برای بسته. |
| `/search <query>` | جست‌وجوی بسته‌ها بر اساس کد لینک یا عنوان. |
| `` `/setexpiry <code> <duration\|0\|off>` `` | تنظیم انقضای موردی بسته (`1h`، `6h`، `24h`، `7d`) یا غیرفعال کردن انقضا (`0`/`off`). |
| `/postbundle <code> [channel_id]` | انتشار کارت بسته همراه با دکمه لینک عمیق در `[channel_id]` یا کانال پیش‌فرض `pub_channel_id`. |
| `/rotatelink <code> [hours]` | چرخش فوری لینک بسته یا تنظیم چرخش خودکار ساعتی (با همگام‌سازی دکمه `/postbundle`). |
| `/delete <code>` | حذف دائمی بسته و ابطال کد دسترسی آن. |

#### کاربران، VIPها و فهرست‌ها

| دستور | شرح عملکرد |
| :--- | :--- |
| `/admins` | نمایش فهرست سوپرادمین‌ها و ادمین‌های عادی ثبت‌شده. |
| `/vips` | نمایش فهرست کاربران VIP فعال و مدت باقی‌مانده. |
| `/addvip <user_id> [days]` | اعطای وضعیت VIP به مدت `[days]` روز (حذف `[days]` برای VIP دائمی). |
| `` `/delvip <user_id\|all>` `` | لغو وضعیت VIP برای یک کاربر یا پاک‌سازی همه VIPها. |
| `/clearvips` | حذف تمام رکوردهای جدول `vips`. |
| `/ban <user_id> [days]` | مسدود کردن کاربر به صورت دائمی یا برای `[days]` روز. |
| `/unban <user_id>` | رفع مسدودیت کاربر `<user_id>`. |

#### تنظیمات سراسری، آمار و عضویت اجباری

| دستور | شرح عملکرد |
| :--- | :--- |
| `/settings` | باز کردن پنل تعاملی تنظیمات ربات. |
| `/setdailylimit <number>` | تنظیم سقف روزانه دانلود بسته (`daily_download_cap`). |
| `/setfilelimit <number>` | تنظیم سقف روزانه دانلود به ازای هر فایل (`file_daily_limit`). |
| `/setautodel <seconds>` | تنظیم تاخیر حذف خودکار پیام‌ها بر حسب ثانیه (`0`، `600`، `3600`، `86400` یا مقدار دلخواه). |
| `/setbundlettl <hours>` | تنظیم زمان انقضای پیش‌فرض بر حسب ساعت برای بسته‌های جدید (`0`، `24`، `72`، `168` یا دلخواه). |
| `` `/setpubchannel <-100...\|off\|clear>` `` | تنظیم یا پاک کردن کانال عمومی پیش‌فرض برای `/postbundle`. |
| `` `/setlang <en\|fa>` `` | تغییر زبان رابط کاربری ربات (`en` یا `fa`). |
| `/stats` | نمایش آمار کلی دانلودها، کاربران، بسته‌ها و وضعیت سیستم. |
| `/top` | نمایش رتبه‌بندی پربازدیدترین بسته‌ها. |
| `/channels` | باز کردن پنل مدیریت کانال‌های عضویت اجباری. |
| `` `/addchannel <chId\|fwd> [limit] [label]` `` | افزودن کانال عضویت اجباری (با شناسه یا فوروارد پیام) همراه با سقف اختیاری عضو و عنوان دکمه. |
| `/delchannel <channel_id>` | حذف یک کانال عضویت اجباری. |
| `/setchannelbtn <channel_id> <label>` | تغییر متن دکمه عضویت برای یک کانال عضویت اجباری. |
| `/setverifybtn <label>` | سفارشی‌سازی متن دکمه تایید عضویت اجباری (`fj_verify_btn_text`). |

### دستورات سوپرادمین (سطح ۳ — سوپرادمین و مالک)

| دستور | شرح عملکرد |
| :--- | :--- |
| `` `/addadmin <user_id> [admin\|super_admin]` `` | ارتقای `<user_id>` به نقش `admin` یا `super_admin`. |
| `/deladmin <user_id>` | عزل ادمین یا سوپرادمین و بازگشت به کاربر عادی. |
| `` `/setlogchannel <-100...\|owner\|off>` `` | هدایت هشدارهای سیستم به کانال (`-100...`)، پیوی مالک (`owner`) یا غیرفعال‌سازی (`off`). |
| `/botprofile` | باز کردن ابزارهای مدیریت پروفایل ربات. |

### دستورات مالک (سطح ۴ — انحصاری مالک)

| دستور | شرح عملکرد |
| :--- | :--- |
| `/setbotowner [target_id]` | ثبت مالکیت در وضعیت صفر (`owner_id = 0`) یا تنظیم/بررسی وضعیت مالک. |
| `/transfer_ownership <target_id>` | شروع انتقال دومرحله‌ای ۶۰ ثانیه‌ای مالکیت (`pending_owner_transfer`). |
| `` `/maintenance [on\|off\|1\|0]` `` | روشن یا خاموش کردن حالت تعمیر و نگهداری (مسدودیت همه غیرمالک‌ها). |
| `/factoryreset` | پاک‌سازی جدول‌های زمان اجرا به حالت کارخانه با حفظ مالک فعلی. |
| `/restore` | در این نسخه غیرفعال است و پیام `restore_not_available` برمی‌گرداند. |
| `` `/setstoragechannel <-100...\|off\|clear>` `` | تنظیم، غیرفعال‌سازی یا پاک کردن کانال ذخیره خصوصی. |
| `/export_config` | خروجی گرفتن از تنظیمات قابل انتقال `system_config` در قالب JSON. |
| `/import_config <json_string>` | اعمال تنظیمات JSON روی کلیدهای `system_config`. |
| `/sql [query]` | اجرای یک کوئری SQLite (تا سقف `40` ردیف پیش‌نمایش) یا نمایش راهنمای کنسول. |
| `/terminal` *(معادل `/console`)* | ورود به حالت ترمینال تعاملی SQLite با تایم‌اوت ۱۰ دقیقه‌ای عدم فعالیت. |

## کلیدهای پیکربندی پایدار (`system_config`)

| کلید | مقدار پیش‌فرض | نقش و عملکرد |
| :--- | :--- | :--- |
| `owner_id` | `0` | شناسه عددی تلگرام مالک ریشه (`0` قفل وضعیت صفر را فعال می‌کند). |
| `storage_channel_snapshot` | — | اسنپ‌شات فراداده کانال ذخیره و وضعیت فعال بودن (`storage_channel_active`). |
| `log_channel_id` / `log_channel_active` | — | مقصد ارسال لاگ‌ها (`-100...` یا `owner`) و وضعیت فعال‌سازی آن. |
| `maintenance` / `maintenance_mode` | `'off'` / `'0'` | در صورت فعال بودن، دسترسی تمام غیرمالک‌ها را مسدود می‌کند. |
| `language` / `default_lang` | `'en'` | زبان فعال دیکشنری ربات (`'en'` یا `'fa'`). |
| `daily_download_cap` | `'0'` | سقف دانلود روزانه بسته برای کاربران عادی (`0` = نامحدود). |
| `file_daily_limit` | `'3'` | سهمیه دانلود روزانه به ازای هر فایل برای کاربران عادی. |
| `auto_delete_seconds` | `'0'` | تاخیر حذف خودکار بر حسب ثانیه (`0` = غیرفعال). |
| `bundle_ttl_hours` | `'0'` | مدت انقضای پیش‌فرض بسته‌های جدید بر حسب ساعت (`0` = بدون انقضا). |
| `default_protect_content` | `'0'` | وضعیت پیش‌فرض پرچم `protect_content` برای بسته‌های تازه ساخته‌شده. |
| `allowed_media_types` | `["photo","document","video","audio"]` | آرایه JSON انواع رسانه مجاز برای آپلود از میان ۸ فرمت پشتیبانی‌شده. |
| `premium_emojis_enabled` | `'false'` | فعال‌سازی رندر ایموجی‌های پرمیوم `<tg-emoji>` (در خطا به صورت خودکار خاموش می‌شود). |
| `pub_channel_id` | — | شناسه کانال عمومی پیش‌فرض برای دستور `/postbundle`. |
| `fj_verify_btn_text` | — | متن سفارشی دکمه اینلاین **تایید عضویت** در عضویت اجباری. |
| `pending_owner_transfer` | — | داده JSON موقت برای توکن انتقال ۶۰ ثانیه‌ای مالکیت. |
| `last_maint_at` | — | برچسب زمان اعمال فاصله CAS سی ثانیه‌ای بین گذرهای نگهداری فرصت‌طلبانه. |
| `maintenance_lease` | — | لیز `180` ثانیه‌ای برای جلوگیری از اجرای هم‌زمان نگهداری پس‌زمینه. |

## ثابت‌های سخت‌کدشده زمان اجرا

ثابت‌های تعریف‌شده در فایل‌های `constants.js`، `rate_limiter.js` و `default_config.js`:

| ثابت | مقدار | کاربرد |
| :--- | :--- | :--- |
| `MAX_BUNDLE_ITEMS` | `25` | حداکثر تعداد آیتم مجاز در یک بسته. |
| `MAX_PER_SESSION_UPLOAD` | `25` | حداکثر تعداد فایل قابل پذیرش در یک نشست `/batch`. |
| `CHUNK_DELIVERY_SIZE` | `10` | تعداد آیتم تحویل‌شده در هر صفحه هنگام ارسال بسته. |
| `MAX_FORCE_JOIN_CHANNELS` | `8` | حداکثر تعداد کانال‌های عضویت اجباری قابل تنظیم. |
| `MAX_OUTGOING_SOCKETS` | `6` | حداکثر درخواست موازی به Bot API در هر موج بررسی عضویت. |
| `FORCE_JOIN_THROTTLE_SEC` | `3` | فاصله زمانی اجباری (ثانیه) بین کلیک‌های دکمه تایید عضویت اجباری. |
| `MAX_ADMINS` | `10` | سقف تعداد ادمین‌های عادی (`admin`). |
| `MAX_ROTATING_ADMIN` | `3` | حداکثر بسته‌های چرخان فعال برای هر ادمین عادی. |
| `MAX_ROTATING_SUPERADMIN` | `10` | حداکثر بسته‌های چرخان فعال برای هر سوپرادمین. |
| `MAX_ROTATING_PER_CHANNEL` | `10` | حداکثر بسته‌های چرخان منتشرشده در یک کانال عمومی. |
| `MAX_STRIKES` | `5` | تعداد تخطی از محدودیت نرخ پیش از اعمال مسدودیت موقت. |
| `LOCKOUT_DURATION_SEC` | `1800` | مدت زمان مسدودیت موقت (`30` دقیقه) پس از رسیدن به `MAX_STRIKES`. |
| `rateLimitMessagesPerMin` | `20` | آستانه پیام ورودی در دقیقه برای هر کاربر در پنجره لغزان. |
| `maxUploadSizeMb` | `50` | آستانه حداکثر حجم تک‌فایل آپلودی بر حسب مگابایت. |
| `sqlConsoleMaxRows` | `40` | حداکثر تعداد ردیف نمایش‌داده‌شده در هر صفحه خروجی `/sql` یا `/terminal`. |
| `transferTokenTtlSec` | `60` | مدت اعتبار توکن دستور `/transfer_ownership` بر حسب ثانیه. |

## جابه‌جایی پیکربندی (`/export_config` و `/import_config`)

مالک می‌تواند با `/export_config` تنظیمات قابل انتقال `system_config` (سهمیه‌ها، TTLها، رسانه‌های مجاز، زبان، شناسه‌های کانال) را در قالب JSON دریافت کرده و در نمونه دیگر با `/import_config <json_string>` بازیابی کند:

```text
/export_config
/import_config {"language":"fa","file_daily_limit":"5","auto_delete_seconds":"3600"}
```
